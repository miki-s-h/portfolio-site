ポートフォリオサイト

制作目的

HTMLとCSSの学習のために制作した自己紹介サイトです。 初めて複数ページ構成のWebサイトを作りました。

使用技術

  • HTML
  • CSS

工夫したポイント

  • 作品カードのレイアウトをFlexboxで作成
  • 画像が崩れないようobject-fitを使用
  • ページ遷移を実装

制作期間

2~3週間

学んだこと

複数ページ間のリンク設定やナビゲーションの実装に苦労しました。特にナビをクリックしたときにスムーズに動く動作を作るのが難しかったです。また、レスポンシブデザインを初めて取り入れ、画面サイズに合わせたレイアウト調整を学びました。
