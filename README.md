# My Web Portfolio
Web制作を学習中に制作した、練習用ポートフォリオサイトです。
HTML・CSSを使い、1ページずつ手を動かしながら作りました。

🔗 **公開サイト**: https://miki-s-h.github.io/portfolio-site/

## 使用技術
- HTML
- CSS(Flexbox、レスポンシブデザイン)
- JavaScript(ハンバーガーメニューの実装、フォームバリデーションなど)
- Canva(ロゴ・バナー・メニュー表・Instagram投稿デザイン)

## 制作について
各ページごとに配色やレイアウトを変え、幅広いデザインパターンに対応できるよう意識して制作しました。

- カフェサイト:あたたかみのある配色
- イベントページ:パステルカラーで華やかな雰囲気
- コーポレートサイト:ネイビー×テラコッタで落ち着いた信頼感を意識
- 猫カフェ Lumière:ブラウン×クリームで店舗イメージの統一感を意識

フォームの入力チェック(`required`属性)や、スマートフォン表示への対応も行っています。
